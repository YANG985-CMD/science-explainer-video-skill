# 手机易读字体与线条动画

所有者于 2026-10-16 在“电流采样”线条动画男声版中确认本规范。适用于后续该所有者的视频排版，以及选择线条动画时的视觉实现。后续明确要求优先。

同日最新明确要求：**“以后视频做线条动画，不做其他的了。”** 因此后续视频直接使用线条动画，不再主动提供或制作等轴 2.5D、实体三维、三维粒子、贴纸等其它动画风格或多风格对比。男声讲解与无配音简约两种解说方式均使用线条动画；解说方式、BGM、语速、泛光和配色仍各自按 brief 执行。只有所有者后续明确更改时才切换动画风格。

## Latest numeric baseline

所有者随后要求保存这版 FOC 的全部实际参数。配色、亮度、泛光和字号以 [foc-bright60-style.json](foc-bright60-style.json) 的 **`foc-line-bright60-v1`** 为准，单位与复用算法见 [foc-bright60-style.md](foc-bright60-style.md)。下表为固定基准，不再凭“明亮 / 香槟金 / 大字”猜数值；用户明确更改时记录具体覆盖值。

## Mobile typography

### 封面：主题最大，问题句次之

- **视频主题名是封面最大、最显眼的文字。** 例如“电流采样”应比“50 A 的电流”和“芯片怎么看见？”都大，不能把主题名做成顶部小标签。
- 已确认构图以 **1920 × 1080 逻辑画布**设计：主题名 **180 px**，本版副标题 **76 px**、封面解释行 **38 px**；4K 对应 **360 px、152 px、76 px**。
- 按题目长度调整位置和断行，保持主题最大这一层级。主题过长时精简为短主题或分行，不应缩成小标签，让问题句反客为主。
- 单独导出同构图封面，并将它实际放进成片开头。检查带底部字幕的开场时刻，不能只有无字幕的封面 PNG 排版正确。

### 正片：粗、大、亮，按手机观看检查

| 文字角色 | 1920 × 1080 逻辑字号 | 3840 × 2160 实际字号 |
| --- | --- | --- |
| 上方主题 / 问题 | 55 px | 110 px |
| 下方讲解字幕 | 52 px | 104 px |
| 图中关键大数值 | 50 px | 100 px |
| 必要标签 / 图例 / 刻度最低字号 | 31 px | 62 px |

- 字号是已确认 FOC 版的明确基准；图中旧调用另按 JSON 的 `max(31,round(requested_size*1.04))` 转换，标题/字幕/封面不经过此转换；按逻辑画布统一缩放一次，避免把 4K 像素误当作 1080p 字号。不同构图可以调整，但不能为了塞下内容把必要文字重新缩细、缩小。
- 默认用 **微软雅黑粗体**或覆盖中文与单位符号的同类清晰无衬线粗体；可用 Noto Sans CJK 的中粗/粗字重替代。避免把细宋体或低字重长句作为手机阅读主体。公式采用可靠数学排版，仍需足够字号和笔画对比，不能乱码。
- 下方字幕优先 1 行，最多 2 行。用实际字体测宽后按语义断行；较长内容拆成更多讲解节拍，或重排图形。图中文字、刻度、数值框与字幕区域之间留出间隔。
- 男声版字幕使用[实际解说原话](narration-subtitle-corrections.md)，不能为了放大字号而改成摘要。先按实际声音拆成短句，再按字宽排版；数值、单位与技术名称保持规范。
- 同一句的文字、数字、彩色强调和标点共用基线。不要把每个片段按各自包围盒独立垂直居中；句末不留孤立句号，标点不能漂到句子中间。
- 标题与底部解释继续按“上方先出现 → 留足阅读时间 → 下方出现，上方保留”错峰入场。加粗放大后重新检查单位与末端刻度、放大器内部符号、数值框等处的挤压。

### 文字颜色

使用 [FOC 数值预设](foc-bright60-style.json) 的明确角色：主文字 `#F8FCFF`，浅蓝 `#B5EAFF`，金色强调 `#FFDA9E`，次级文字 `#B1CADC`，紫 `#C3B3FF`，粉 `#F5A3C2`。正文实心绘制，无文字泛光；关键词、数值及单位与对象使用同一角色色，不再采用旧版较鲜艳但不同于成片的起点值。

## Line-animation preset

**线条动画是该所有者后续视频统一采用的视觉表现方案**，搭配男声讲解或无配音简约风。无需再次确认是否选择线条动画。配音、BGM、速度、泛光和配色继续遵循当次 brief；例如要求无 BGM 时，成片只映射解说音轨。

- **主体用可辨认的轮廓来画。** 用电机、电阻、放大器、芯片、连杆、坐标轴、波形或运动轨迹承担解释；标签贴着对应对象。轮廓应有结构细节，不能整片仅用文字框图或一个循环波形代替机制。
- **线条的变化表达因果。** 输入变化 → 同一模型状态更新 → 对应波形、数值和器件响应同步变化。曲线沿时间绘制，采样标记对应真实取样位置，信号沿有意义的通路传递。
- **检查实际运动的连续性。** 波形游标、曲线交点和旋转矢量使用同一连续时间/相位；用解析计算或插值求每帧的位置，避免把连续运动取整到数组索引后产生停顿、跳点。提高输出帧率时生成对应的新运动帧；真实采样保持、开关跳变等离散现象仍按物理含义保留。
- **变化视角以推进解释。** 系统全貌 → 局部结构 → 波形 / 数值 → 回到信号链；同一器件或信号通过移动、缩放和重排带入下一段。继承[动态科技风](dynamic-tech-style.md)的缓动、错峰文字和稳定观察时间。
- **泛光选中时使用细亮线芯。** 参考所有者认可的带泛光 PMSM 参数识别长视频与本次采样电阻线条版：中心明亮、线芯清晰，周围近/远两层柔光；亮度与柔光宽度独立于实体描边厚度。固定采用 [FOC 参数](foc-bright60-style.md)：普通波形 4K 描边 **3 px**、中心亮芯 **1 px**；主矢量箭头 **5 / 2 px**；彩色投影 **2 / 1 px**。芯颜色混白 **27%**；近/远泛光在 960 × 540 层的半径分别 **1.6 / 7 px**，通道增益 **1.55 / 1.05**。其它线宽按 JSON 转换公式计算，不能靠加粗补亮。
- **光效保留语义。** 箭头头部保留清晰尖端，不加装饰性发光圆球。曲线与采样线交点、当前采样点、扫描头或有状态含义的节点可以有光点。坐标轴上不能出现无意义游动黑点或遮罩痕迹。参考轴、网格与非活动连线保持低亮。
- **泛光模式独立执行。** 低泛光降低近/远光晕，无泛光使用同样清楚的轮廓与运动；两者均保留可读粗体、数据关系和因果动画。

## Encoded review

- 将实际编码的开头和代表性画面缩到 **960 × 540**，再用 **640 × 360** 抽查；保持整个横屏画面可见、不放大局部，检查手机观看的字号、字重与颜色对比。主题名、下方解释和关键数值应能直接读清。
- 分别检查封面无字幕、字幕出现后、最长字幕、公式、最密集刻度、正负数值变化和图中标签位置。挤不下时删减并重排内容，再渲染检查。
- 检查实际编码转场前、中、结束后数帧及连续播放：不能残留上一句、双曲线或多余图层；同一主体的延续应清楚，稳定帧无重影。
- 线条泛光不能把细芯撑成粗管，不能模糊文字、抹掉交点或压住图例；箭头尖端与有意义的采样光点应可区分。
- 对游标/交点连续移动的片段检查实际相邻帧，确认没有无意义的重复位置或大步跳动；不能仅凭视频文件标注的帧率判断丝滑程度。手机尺寸下检查线芯亮度，亮度与柔光宽度的调整不应靠加粗描边实现。
- 改字体、标题或字幕后同时更新实际视频和单独封面；变速时同步调整人声与字幕时间，并保持所选声线的音高。
