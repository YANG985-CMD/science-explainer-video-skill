# FOC 明亮线条版：数值参数

本文件与 [foc-bright60-style.json](foc-bright60-style.json) 记录所有者在 2026-10-16 指定保存的实际成片参数，预设 ID 为 **`foc-line-bright60-v1`**。依据是《FOC原理_线条动画_4K60帧_读音与连读修正版》的实际渲染代码和覆盖后的运行参数，不是从参考图猜色。JSON 为机器读取的唯一数值来源；本文件解释单位、组合顺序和复用方式。

以后该所有者要求沿用当前配色、亮度或线条效果时，直接加载此预设。**“冰蓝”“香槟金”“明亮”“标准泛光”只能作显示别名，不能代替 HEX/RGB、线宽、模糊半径、增益和字号。** 这套数值覆盖旧参考中较暗的推测色值和“字号起点”描述；动态参考中的承接、动感、错峰文字规则继续保留。当前用户明确改变的字段优先，其余字段不凭感觉重设。旁白、BGM、速度和泛光选择仍独立。

## 画布和颜色

逻辑画布 1920 × 1080；实际渲染 3840 × 2160，缩放系数 **2**；构图增益、字体增益均为 **1.0**，偏移均为 **0**。原生生成 **60 fps** 运动帧。不要沿用旧底层文件中被覆盖的 `G=1.14`、`FONT_GAIN=1.10`、30 fps 或较暗的初始色板。

| 角色 | HEX | RGB |
| --- | --- | --- |
| 背景基色 | `#060A11` | 6, 10, 17 |
| 主文字 / 标题 / 普通字幕 | `#F8FCFF` | 248, 252, 255 |
| A 相 / 主信号浅蓝 | `#B5EAFF` | 181, 234, 255 |
| 操作 / 关键数值金色 | `#FFDA9E` | 255, 218, 158 |
| B 相 / 第二信号紫色 | `#C3B3FF` | 195, 179, 255 |
| C 相 / 第三信号粉色 | `#F5A3C2` | 245, 163, 194 |
| 次级文字 / 刻度 | `#B1CADC` | 177, 202, 220 |
| 非活动轴线 / 网格 | `#354B60` | 53, 75, 96 |

三相信号颜色顺序固定为浅蓝 → 紫 → 粉。旧实现里的变量 `PINK` 实际指紫色、`PURPLE` 实际指粉色；复用时按上述语义角色读取 JSON，不按旧变量名字猜色。非活动轴线与白色文字不添加曲线泛光。

背景不是纯色，坐标以实际输出像素计：`g = exp(-2*((((x/W)-0.5)/0.45)^2 + (((y/H)-0.46)/0.7)^2))`，每通道取 `floor(clip(背景基色 + g*[2,4,6], 0,255))`。无噪声、无额外曝光滤镜。

## 细线芯和这次亮度

完整显现时不透明度 **1.0**。输入线宽先转换：`logical_width = clamp(request_width*0.58, 0.75, 3.0)`；4K 实体描边为 `max(1, round(logical_width*2))`。所有 `round` 按 Python 的四舍六入五成双执行。

| 线条角色 | 输入线宽 | 4K 实体描边 | 4K 明亮内芯 |
| --- | --- | --- | --- |
| 波形曲线 | 3 | 3 px | 1 px |
| 电流 / 坐标投影矢量箭头 | 4 | 5 px | 2 px |
| 彩色辅助投影线 | 2 | 2 px | 1 px |
| 参考坐标轴 | 1 | 2 px | 不加亮芯、不泛光 |

明亮内芯颜色为 `round(0.73*原通道 + 0.27*255)`，内芯宽度为 `max(1, round(实体描边宽度*0.42))`。因此浅蓝、金、紫、粉内芯分别为 `#C9F0FF`、`#FFE4B8`、`#D3C8FF`、`#F8BCD2`。**中心提亮用 27% 白色混合；不要靠加粗实体线补亮。** 1080p 预览从 4K 下采样时，这些实体描边对应 1.5、2.5、1、1 px。

泛光只对这四个彩色角色产生。以下模糊半径的原始单位是 **960 × 540 泛光画布像素**，不是 4K 像素：

| 参数 | 保存值 | 等效 4K 值 |
| --- | --- | --- |
| 泛光种子 RGB 增益 | 0.98 × 对象不透明度 × 场景增益 | 相同 |
| 泛光种子线宽 | `max(1, round(logical_width*2/4*1.6))` | 放大 4 倍 |
| 近层 GaussianBlur 半径 | 1.6 px | 6.4 px |
| 近层模糊后通道增益 | 1.55 | 相同 |
| 远层 GaussianBlur 半径 | 7.0 px | 28 px |
| 远层模糊后通道增益 | 1.05 | 相同 |
| 活动区域裁切外扩 | 24 px | 96 px |
| 泛光层放大 | 4 倍，双线性插值 | 960 × 540 → 3840 × 2160 |
| 全局曝光增益 | 1.0 | 相同 |

合成顺序：绘制实体描边和内芯 → 记录几何和文字保护遮罩 → 泛光种子分别模糊 → 各层乘增益并限制通道到 255 → 近远层饱和相加 → 双线性放大 → 乘保护遮罩反相 → 与原画面饱和相加。使用 RGB 加法，**不是 Screen 混合**。保护原线芯和文字，避免累加变成粗白管；半透明几何与当前画面做 alpha 合成，不能先与黑背景混合后覆盖坐标轴。

曲线 / 采样线交点可以有光点：输入半径 4，经 `max(2, r*0.6)` 得逻辑半径 **2.4 px**（4K **4.8 px**）。光点芯混白 **28%**，芯半径 `max(0.65, r*0.32)`，低分辨率泛光种子增益 **0.90**；独立径向光晕的完整公式保存在 JSON。箭头尖端不加光球。无泛光时保留同样颜色、实体线芯和字体，仅关闭光晕；本确认版没有测定低泛光倍率，不能把猜测值说成已确认参数。

## 字号、字重和位置

使用 **微软雅黑粗体，`msyhbd.ttc`，700 字重**。字号指字体 nominal/em 像素尺寸，不是字形包围盒高度。实际像素只乘缩放系数一次：

| 文字角色 | 1920 逻辑字号 | 4K 实际字号 |
| --- | --- | --- |
| 封面主题 FOC | 180 px | 360 px |
| 封面副标题 | 76 px | 152 px |
| 封面解释行 | 38 px | 76 px |
| 正片上方标题 | 55 px | 110 px |
| 下方讲解字幕 | 52 px | 104 px |
| 必要标签 / 图例 / 刻度最低字号 | 31 px | 62 px |
| 关键大数值（原调用 48） | 50 px | 100 px |
| 常规公式 | 52 | 104 |
| 长公式（Clarke / Park / inverse / aw） | 48 | 96 |
| 反电动势长公式（本视频特定布局） | 42 | 84 |

图中旧调用字号的准确转换为 `max(31, round(requested_size*1.04))`，再乘 2；例如原 31→32→64 px，原 38→40→80 px，原 40→42→84 px，原 48→50→100 px。标题、字幕、封面和直接公式不经过这条 1.04 转换。数学使用 MathText `cm` 数学字体、144 dpi（相对 72 dpi 为 2 倍）；不能把数学字号和实际像素再次乘 2。长公式原实现按实测宽度逐级减小 1 个逻辑字号；新视频优先重排或分步展示，变动的最终字号须显式记录，不能笼统写“大字体”。

位置均为逻辑坐标：上方标题中心 `(960,108)`；单行底部字幕中心 `(960,1000)`；双行字幕中心 y 为 **958、1023**，行中心距 **65 px**。字幕最大实测行宽 **1720 px**（4K **3440 px**），左右各留 **100 px**（4K **200 px**）。封面主题、副标题、解释行中心分别为 `(960,215)`、`(960,390)`、`(960,920)`。所有文本实心绘制、无文字泛光；同句各颜色片段共用基线，去掉句末孤立中文句号。数字、单位、Clarke/Park/FOC 的强调色使用 `#FFDA9E`。

普通场景标题从 **0.08 s** 开始淡入 **0.65 s**，伴随 **9 px** 位移、持续 **0.70 s**；图形从 **1.05 s** 开始、淡入 **0.70 s**；首句下方字幕通常从 **2.0 s** 开始，上方保持。字幕淡入 / 淡出各 **0.07 s**，后续字幕严格跟随最终人声声学对齐，不额外延迟。缓动为 `p*p*(3-2*p)`。这些是本成片的具体参数，不代替因果运动与内容所需观察停顿。

## 导出和复用检查

原生 4K 60 fps；RGB24 输入 → BT.709 limited/tv、yuv420p。原始分镜使用 H.264 NVENC `p5 / hq / vbr / CQ17 / GOP120`；本修正版字幕局部重新编码的分镜用 **CQ14**，其它分镜原码流复用。CQ14 是这次避免二次编码损失的设置，不能误记为发光增益。

制作设置保存 `visual_preset: foc-line-bright60-v1`、实际加载的 JSON 文件 SHA-256 和逐项数值覆盖。优先读取 JSON，不能仅写色名；不要把此预设关联成自动更换男声、配 BGM 或变速。检查实际编码的封面、最长字幕、坐标轴、四种曲线、曲线交点和相邻运动帧；缩到 960 × 540、640 × 360 检查阅读与细线对比。若改颜色或亮度，另存有具体数值的新版本，不覆盖本已确认基准。
