## 转场：让对象带着解释进入下一镜

- 先写清楚：这一镜保留什么，什么发生操作，什么成为下一镜的主体。优先使用同一对象的位移、缩放、重排、局部展开或由局部到整体的视角变化。
- 结果应有生成过程：曲线沿时间画出，活动点扫过采样值，格点按逻辑顺序亮起，输入经过操作后构成输出。光点须指示扫描位置、计算步骤、信号流或当前状态，不能无目的地绕圈。
- 当概念切换时，让旧结构降低亮度作为短暂上下文，新主体进入前景；上下文无用后清除。保留背景必须有明确的解释用途，不能因图层未清理留下残影。
- 公式、短句与机制共享构图。可以把问题句缩小上移，把其中的关键词或量迁移到公式/图中，再展开主图；不必每镜都重新刷出同一个上标题、下曲线模板。
- 对不相关构图，短淡出/淡入仍适用。不要为保持运动而强行伪造物理变换，也不要用全屏文字叠化代替承接。
- 结论可以暂时安静，短标题可作为开场、章节标点或收束；原理段仍需有机制、对象或数据动作。不要把连续解释改成长时间纯文字、公式或表格页。

## 文字：按意义揭示，出现后让人读得完

- 主问题/关键词可逐字或分短语显现：每个单元有柔和的透明度变化，可配短光标、下划线或小幅遮罩揭示。不是每个字幕都打字，也不是把全段文字逐字拖很久。
- 决定最终排版后再揭示，给未出现字保留位置，避免每多一个字就重新居中、换行或挤动图形。
- 文字涉及一个具体对象时，从那个对象附近出现，或让同一关键词/编号沿有意义的路径进入目标位置。图形变化和说明互相对应。
- 图中标签随对象运动；正文与旁白字幕尽量保持稳定，避免观众一边追字一边读公式。无配音模式用场景内短文案完成解释，不重复增加底部逐字稿。
- 不同句子共用位置时，旧句先退场，新句再进入；共享关键词可保留，其余内容清理。不要让两句完整文字交叉叠化。
- 使用清晰的大字层级与留白。宋体/衬线风格适合短标题，图中小标签优先清晰可读；英文/双语只在有信息价值时加入，不强制照抄参考。
- 所有数值仍使用阿拉伯数字和标准单位。揭示结束后必须有完整可读的稳定停顿；不以加快字幕速度换取动感。

## 配色：冰蓝香槟金

以可见画面归纳的工程实现色板，**不是提取到的原作源代码色值**：

| 角色 | 设计色值 | 用途 |
| --- | --- | --- |
| 主背景 | `#060A11` | 深黑蓝，保持暗而安静。 |
| 主文字 | `#E8EDF2` | 冷白/象牙白，保证阅读。 |
| 结构与信号 | `#A8D8F0` | 浅冰蓝，用于轮廓、参考信号与关联节点。 |
| 当前操作/焦点 | `#E6C68B` | 香槟金，用于扫描头、选中项、关键结果。 |
| 次级注释 | `#718698` | 蓝灰；不能淡到必要标签无法读。 |
| 非活动结构 | `#26394A` | 轴线、网格、退后的上下文。 |
| 可选第二状态 | `#9C91D9` | 柔紫，用于有实际含义的类别区分。 |
| 可选第三状态 | `#D28FA5` | 低饱和玫瑰色，仅在需要时使用。 |

- 大部分面积保持深色与冷白，冰蓝承载结构，香槟金集中引导一次一个焦点。多类数据需要更多颜色时有明确图例，并辅以实心/空心、实线/虚线等形状区分。
- 某一信号的颜色身份应保持；金色高亮可以是叠加的操作光标、局部选区或外环，不必把同一信号反复换色。若展示的就是状态变换，必须让标签/图例同步。
- 标准泛光采用局部柔光与清晰线芯，不让整个网络、全部文字和所有曲线同时发亮。低泛光/无泛光遵循当前选择。背景轻微暗部渐变、纹理或稀疏微粒只能从属，不能代替机制或影响读图。
- 原“金色强调”仍是可选色板；“冰蓝香槟金”替代以前的深蓝青金。不要未经确认把候选蓝紫/B2 或旧高饱和青金称为新版参考配色。

## 动感与节奏：动作、观察、再推进

- 每个解释段有建构/动作、可观察结果、下一层推进。移动对象、绘制轨迹、改变焦点、重构图与静止对比交替使用，避免全片只循环一种图。
- 选一个主要动作让观众跟随。构图有前后层级、动作有先后；不要同时移动所有物体、出现整段文字并变换坐标轴。
- 同一大图持续较久时，检查它是否在展示新的状态、层级、局部或结果。若只是循环原动画，应重写分镜；不为“动”而按固定秒数强制切镜。
- 运动曲线采用起止缓动，适时加速、减速、停顿。连续扫描可匀速，以保证位置与数据对应。不得平滑篡改实验数据或优化迭代记录来换取视觉丝滑。
- 原作出现短暂色散，可用于表达一次明确的矛盾/状态冲突；这是可选的转折效果，不是常驻滤镜。若使用，应短暂、可控、迅速恢复清晰，不能在稳定读图帧中留下双字、模糊或误导性曲线。
- 动感来自对象与解释的变化，不通过擅自加速整片、更换声线、持续抖动镜头或增加无意义光效获得。

以下仅为原创实现起点，不是原作测量值：共享对象的移动/重构图约 0.6–1.2 秒，短语揭示约 0.4–0.8 秒，相关元素错峰可间隔约 0.08–0.18 秒，完整扫描/建构可用 2–6 秒，再给稳定观察时间。逐字揭示要根据句长单独安排；复杂操作和公式允许更长，不必把所有动作塞进这些区间。

## 分镜与验收

在原有分镜记录中加入：

```yaml
visual_reference: douyin_7692591222837300507
palette: midnight_ice_blue_champagne
carry_object: same_scientific_object_or_signal
operation: input_changes_then_result_is_constructed
transition: reframe_shared_object_or_move_local_detail_into_focus
text_reveal: phrase_or_character_mask_then_readable_hold
focus: one_active_point_or_region
settled_hold: long_enough_to_read_and_compare
```

以 SPWM/SVPWM 为例：沿同一电角度扫过三相参考 → 同时标记当前最大/最小值 → 生成共同偏置 → 将这个偏置加入同一组三相 → 绘制马鞍波，再稳定比较线电压不变。所有数值由同一模型状态计算；不是随机移动光点或在不同静态图之间轮播。

成片检查除原有要求外，还需回答：

- 能看出每次转场保留了哪个对象，以及为什么换到这个视角吗？
- 文字是渐进揭示，还是跳出/重新换行/居中抖动？揭示完成后读得完吗？
- 活动光点、扫描、绘制结果与真正的模型状态同步吗？
- 冰蓝结构、香槟金焦点、冷白正文和低亮背景是否有层次？颜色是否有实际角色？
- 前后景切换后，旧图层是有意上下文还是意外残影？最终稳定帧是否清晰？
- 有没有一段只有同一个循环、文字列表或表格，未增加可见解释？
- 观看实际编码片段并检查转场前、中、后的帧；不要以静态预览或分镜文档代替运动验收。
